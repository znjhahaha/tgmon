分享链接与防刷

管理员在消息页可对单条消息生成分享短链（/s/{token}），持有者免登录 查看该条内容并下载图片/视频。应用内已按 IP 限流：分享页 20 次/分、下载 10 次/分。域名走 Cloudflare 橙云时可再叠一层边缘限流（强烈建议）： 

Cloudflare 控制台 → Security → WAF → Rate limiting rules：
规则 1：URI Path starts with "/s/"          → 30 requests / 10 seconds / per IP → Block 1m
规则 2：URI Path starts with "/media/private/" → 30 requests / 10 seconds / per IP → Block 1m

短链 token 为随机 96 bit，库中只存哈希；撤销与过期都在服务端校验。 分享页不含站内其它链接，拿到一条链接的人无法顺藤摸到别的消息。
