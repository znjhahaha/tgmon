# 20260905-wiki-terms-05

Wiki candidates without usable Chinese names are rejected and retained for
inspection. Simplified Chinese names are recovered from Fandom's `zhs` language
field and other supported infobox/language fields. Existing invalid pages and imported terms are repaired at startup;
repeated migration preserves counts and rejection decisions survive later syncs.

The review page supports game/category/status filters, selection, filtered batch
actions, editable Chinese names and pagination. Updates refresh the visible
list and review counters. Locally corrected names survive synchronization, and
revoking a Wiki-owned term removes it from translation without disabling a
matching official term.

Translation now scopes both terminology and entity context to the resolved game.
Reviewed, unambiguous source terms retained by the provider are corrected in new
and cached translations, preserving URLs, code, identifiers and numbers.

Local validation includes 261 pytest cases. Desktop (1440x1000) and mobile
(390x844) browser checks passed for selection, filtered batch actions, rejected
name correction, cross-game isolation, count refresh and pagination.

Release verification uses a database copy before switching services and retains
the previous image, application source and a consistent SQLite backup. The live
verification script uses a simulated translation provider and captures QQ
delivery locally; it does not call a provider or upload/send QQ media.
